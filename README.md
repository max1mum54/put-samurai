# Путь самурая — первая PWA-сборка

Разместите содержимое папки на HTTPS-хостинге. На iPhone откройте адрес в Safari → Поделиться → На экран «Домой».

Данные сохраняются локально в localStorage этого браузера/устройства. Облачной синхронизации и резервного копирования пока нет — не очищайте данные сайта без резервной копии.

Реализованы базовые экраны: Сегодня, недельный план, заметки, персонаж/XP, цели года с пунктами и подпунктами, еженедельный отчёт, тренировки/библиотека упражнений, здоровье, финансы в гривнах и календарь.

Это рабочий прототип, а не финальный релиз. Следующим этапом нужно доработать и протестировать: точную математику процентов в дереве целей (100%), визуальные стадии самурая, переносы и защиту истории задач, автоматический бонус идеального дня, расширенную аналитику тренировок/здоровья, мультивалютные финансы/курс НБУ/накопления, полноценную историю отчётов, экспорт и синхронизацию. В текущей сборке за выполненную задачу начисляется 20 XP; снятие отметки возвращает XP. Бонус идеального дня пока не начисляется автоматически — правила корректировки нужно отдельно утвердить.
